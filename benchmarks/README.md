# Український benchmark авторства: ELTeC v1

Це відтворювана перевірка **стилометричної компоненти DIMS** — відстаней між текстами
(Burrows Delta, Cosine Delta з еталонною нормалізацією), а не точності методики DIMS загалом.
Вона не оцінює bootstrap, інтегральний показник R_DIMS, сучасні новини чи Telegram.

## Джерело й відтворення

[ELTeC-ukr](https://github.com/COST-ELTeC/ELTeC-ukr), Dmytro Yesypenko та Mykhailo Nazarenko,
версія 0.5.0 (2021), [DOI](https://doi.org/10.5281/zenodo.4662731).
Зафіксована ревізія: `a8c3d71301cdba767e33551ff0099da1dc51681a`.
README корпусу описує 50 текстів; у цій ревізії є 49 XML. Для кожного включеного файлу
перевірено українську мову та ліцензію [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Тексти не зберігаються в цьому репозиторії. Маніфест містить назви, авторів і SHA-256.

Із кореня репозиторію, у віртуальному середовищі:

```sh
python -m pip install -r engine/requirements-benchmark.txt
git clone https://github.com/COST-ELTeC/ELTeC-ukr /tmp/ELTeC-ukr
git -C /tmp/ELTeC-ukr checkout a8c3d71301cdba767e33551ff0099da1dc51681a
python engine/tools/authorship_benchmark.py --corpus-dir /tmp/ELTeC-ukr --output-dir engine/benchmarks/eltec-v1
cd engine/benchmarks
jupyter nbconvert --to notebook --execute --inplace eltec-benchmark.ipynb
```

Повторний прогін також створює `pair_scores.csv` та експериментальні еталони; вони
доступні локально, але не включені в git. Виробничий еталон не замінюється.
Notebook читає збережені таблиці; для перевірки самого рушія потрібно запустити CLI вище.

## Протокол

- «Хіба ревуть воли…» (`UKR18801`) виключено через співавторство; псевдонім О. Яковенко
  об'єднано з Олександром Кониським.
- Еталон: 13 творів 11 авторів. Калібрування: 13 творів 12 інших авторів.
  Оцінювання: 22 твори 7 інших авторів. Автори між трьома групами не повторюються.
- Оцінювання: Квітка-Основ'яненко, Марко Вовчок, Франко, Грінченко, Кобилянська,
  Леся Українка, Кащенко. Вибір авторів потребує кількох творів; це не випадкова
  репрезентативна вибірка всього українського письменства.
- До трьох неперекривних уривків із твору, рівномірно розташованих у його основному тексті.
  Заголовки, редакційні примітки й позначені цитати вилучені; діалоги збережені.
- Довжини 250, 500, 1000, 2500, 5000 **слів до фільтрування**. Два варіанти токенізації:
  поточне вилучення однолітерних слів та їх збереження. В обох ті самі вихідні уривки.
- 100/200/300/500 найчастотніших слів, Burrows Delta та Cosine Delta. Еталонні частоти
  й нормалізація обчислені лише на групі еталона, через функції поточного рушія.
- Поріг — заздалегідь вибраний 1-й процентиль відстаней між **різними авторами**
  калібрувальної групи. Результати оцінювання для вибору порога не використовуються.
- Позитивні приклади — той самий автор, **різні твори**; негативні — різні автори.
  Уривки одного твору між собою не оцінюються. Таблиця також містить усереднення
  чутливості за авторами та частоти хибних спрацювань за парами авторів.

## Результат поточного варіанта, 100 частотних слів

| Слів | Метод | Знайдено пар спільного автора (TPR) | Хибні спрацювання на різних авторах (FPR) | ROC AUC |
|---:|---|---:|---:|---:|
| 500 | Burrows | 0,93% | 0,11% | 0,650 |
| 500 | Cosine | 11,57% | 1,45% | 0,746 |
| 5000 | Burrows | 31,41% | 0,14% | 0,925 |
| 5000 | Cosine | 51,28% | 1,08% | 0,952 |

На 500 слів є 216 позитивних і 1863 негативні пари, на 5000 — 156 і 1388.
Це залежні спостереження з лише семи авторів, тому їх кількість не означає тисячі
незалежних випробувань. Довірчих інтервалів і гарантії FPR 1% тут немає.
Калібрувальний процентиль не дорівнює ймовірності спільного авторства.

Cosine краще ранжує пари на цій вибірці, але його чутливість не слід порівнювати з
Burrows як перевагу при однаковій FPR: фактичні FPR різні. Збереження однолітерних
слів часто покращує AUC, але не всі робочі показники. Збільшення кількості ознак
також не дає універсального покращення. Жоден варіант не обрано для виробничого
рушія за цими результатами: після вибору потрібна нова незалежна перевірка.

Наступна перевірка: повний алгоритм із bootstrap на незалежній сучасній українській
вибірці, оцінка залежності від теми/жанру та неоднакових довжин текстів. Історична
художня проза сама по собі не підтверджує якість стилометрії на текстах моніторингу
відкритих джерел (новини, Telegram, транскрипти відео).
