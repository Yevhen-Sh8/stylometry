# Еталонна статистика мов для стилометрії DIMS

Класичний Burrows' Delta нормує частоти слів середніми й відхиленнями, порахованими
по самому порівнюваному набору текстів. Тоді відстань пари залежить від того, що ще
лежить у наборі, а для двох джерел z-оцінки завжди ±1 і Delta ≈ 2,0 незалежно від
схожості текстів. Тому словник (100–500 найчастотніших слів) і статистики беруться з
великого еталонного корпусу мови — аналог `z.scores.both.sets = FALSE` у пакеті
`stylo` (Eder, Rybicki, Kestemont 2016). Код — `core/reference.py`, побудова —
`tools/build_reference.py`.

Кожен файл також містить **розподіли відстаней випадкових пар** незалежних текстів
мови для довжин 125, 250, 500, 1000 і 2000 слів (обидві метрики, 100 ознак). З них:

- **автоматичний поріг** пари — відстань, ближче за яку стоять лише 1 % випадкових пар
  текстів такої самої довжини (довжина коротшого тексту пари);
- **перцентиль** пари — частка випадкових пар, ближчих за цю пару (0 — ближча за всі).

Це емпіричне обґрунтування порога замість експертно призначеного 0,8 (розділ 10
`docs/model_dims_ua.md`). Калібрування є лише для 100 ознак (MFW = 100); для іншої
кількості ознак поріг задається вручну.

| Мова | Джерело | Ліцензія | Документів | Шматків × слів |
|---|---|---|---:|---:|
| uk | Браунський корпус української мови (good, so-so) + UD Ukrainian-IU | CC BY-NC-SA 4.0 | 318 | 780 × 1000 |
| ru | UD Russian-Taiga + UD Russian-GSD | CC BY-SA 4.0 | 224 | 1090 × 1000 |
| en | UD English-EWT | CC BY-SA 4.0 | 70 | 159 × 1000 |
| pl | UD Polish-PDB + UD Polish-LFG | CC BY-NC-SA 4.0 / GPL-3.0 | 131 | 267 × 1000 |
| de | UD German-GSD | CC BY-SA 4.0 | 83 | 198 × 1000 |

Файли містять лише агреговані частотні статистики (без текстів). Ліцензії
некомерційні (NC) для uk і pl — використання в межах наукового дослідження.
Токенізатор — `ct-tok-2` (`core/analysis.TOKENIZER_VERSION`); зміна правил
токенізації вимагає перебудови всіх еталонів (нова версія → новий `vocab_id`).

наукової гілки без змін у числах.
